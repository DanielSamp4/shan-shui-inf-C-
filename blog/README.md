# Caderno interativo

Primeira entrega do blog interativo do projeto: uma explicação visual de como
uma semente vira uma montanha de tinta. A página é estática, sem dependências,
e pode ser aberta a partir de `dist/index.html` ou hospedada como Site.

O objetivo não é reproduzir integralmente o algoritmo de produção do C++; é
isolar seus conceitos para que possam ser compreendidos e testados na leitura.
